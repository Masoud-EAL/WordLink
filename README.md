# WordLink

WordLink is a word learning app that helps users improve their reading and vocabulary skills.

This repository serves as the canonical URL for the WordLink app. Visiting [masoud-eal.github.io/wordlink](https://masoud-eal.github.io/wordlink/) redirects to the full app hosted at [LearntoRead](https://masoud-eal.github.io/LearntoRead/).

## About

WordLink / LearntoRead is an educational tool designed to support reading development. The source code and full application live in the [LearntoRead repository](https://github.com/Masoud-EAL/LearntoRead).
